# Roadmap

## Phase 0: Product Definition

- Define commercial promise.
- Define ideal client profile.
- Choose test sectors.
- Choose initial platforms.
- Define compliance limits.
- Define approval model.
- Define success metrics.
- Define packaging and pricing.

## Phase 1: Internal Prototype

- Accept a user-provided site/source list.
- Use Reddit, YouTube, X, Telegram, and permitted Facebook API or assisted-mode flows.
- Build a central database.
- Run orchestration in n8n.
- Use AI only after rule-based filtering.
- Require human approval for all public or direct messages.
- Generate AutoPostForm records for approved draft review.
- Log every important decision.
- Produce a daily report.

## Phase 2: Hort Americas and AgNSEE Test

- Validate signal quality.
- Measure false positives.
- Measure cost per qualified opportunity.
- Measure time saved.
- Validate approval workflow.
- Treat this as an operational lab, not final market proof.

## Phase 3: High-Volume Case Study

- Test with a company whose prospects actively discuss needs online.
- Track generated conversations, meetings, CRM opportunities, and ROI.

## Phase 4: Reusable Product

- Standardize onboarding questionnaire.
- Standardize workflows.
- Standardize prompts.
- Standardize data models.
- Standardize reports.
- Standardize roles, permissions, backups, and documentation.

## Phase 5: Commercialization

- Launch Pilot, Growth, and Enterprise offers.
- Define source quotas.
- Define support levels.
- Define integration tiers.
- Define dedicated environment rules for sensitive clients.

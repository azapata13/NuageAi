# NuageAI

NUAGEai is the company and product framework. It should be treated as the long-term asset.

## Framework Components

- Hermes: supervised AI engine.
- Atlas: documentation and knowledge base.
- Sentinel: security and compliance controls.
- Logger: operational event capture.
- Dashboard: operations and business visibility.
- Connectors: CRM, Slack, email, social APIs, and external systems.
- Templates: reusable product and client templates.
- Products: MarketingAuto, SalesAuto, SupportAuto, FinanceAuto.

## Repository Strategy

The ideal GitHub organization should eventually contain:

- `hermes-platform`: infrastructure, workflows, prompts, database, security, scripts, tests.
- `nuageai-playbooks`: prompts, SOPs, procedures, architecture, templates, onboarding, standards.

This current repository is acting as the first foundation for `hermes-platform`.

## Product Principle

Clients buy outcomes and productized solutions. n8n is an internal orchestration tool, not the customer-facing product.
